# Ruffle (vendored)

This folder holds an unmodified copy of the self-hosted web build of Ruffle, the
Flash Player emulator: https://ruffle.rs, source https://github.com/ruffle-rs/ruffle

- Version: 0.8.0-nightly.2026.10.11 (see package.json)
- Files: `ruffle.js` and the "MVP" WebAssembly module (`ruffle_web-wasm_mvp_bg.*.wasm`),
  from the release `nightly-2026-10-11`, package `ruffle-nightly-2026_10_11-web-selfhosted.zip`
  (SHA-256 52f8ba5b62667619c8b07b4469cf82a0dab90b856c901e2bdeccc5f8a99aa221; the files here are
  byte-identical to the ones in that package).
- License: MIT OR Apache-2.0, at your option (`LICENSE_MIT`, `LICENSE_APACHE`).
  Copyright (c) 2018 Ruffle LLC and Ruffle contributors.

`ruffle-wasm.js` is generated by gb2swf from the .wasm file: the same module,
gzip-compressed and base64-encoded, so that the player can hand it to Ruffle when
the page is opened from disk (browsers do not allow fetch() on file:// pages).
